## Quickstart
1) Pick a collection and choose a variant (wallpaper, poster, pattern, branding).
2) Select format:
    - PNG/JPG for instant use
    - SVG/PDF for editing or print‑perfect output
3) For print, confirm scale=100%, bleed needs, and DPI per guidelines below.

## What’s inside
- Logos and marks (primary/secondary, monochrome, inverse, clear‑space guidance)
- Patterns and textures (tileable and full‑bleed variants)
- Posters and printables (A‑series and US sizes with bleed/safe margins where applicable)
- Device wallpapers (mobile, tablet, desktop aspect ratios)
- Stationery and bookmarks (print‑ready PDFs and high‑DPI PNGs)
- Apparel/merch graphics (vector where available)
- Icons, badges, and stickers (SVG/PNG with transparency)

## Technical specs
- Formats
  - SVG: fully scalable vectors for editing and large‑format
  - PDF: print‑ready documents at exact dimensions
  - PNG: lossless, crisp edges, supports transparency
  - JPG: lightweight for web and previews
- Color
  - Default: sRGB for screens
  - CMYK variants: provided when applicable (e.g., Coated FOGRA39 or US Web Coated SWOP); confirm with your print shop
- Resolution
  - Print targets 300 DPI (posters may be 150–200 DPI for viewing at distance)
  - Wallpapers optimized per device and aspect ratio
- Metadata
  - Where supported, files include basic XMP metadata for title, author, and license

## Using the assets
- Digital
  - Match aspect ratios (16:9, 3:2, 4:3, tall mobile).
  - Prefer PNG when transparency is needed; JPG for lighter file sizes.
  - Keep sRGB; export at native resolution to preserve sharpness.
- Print
  - Prefer PDF or SVG for scale‑accurate output.
  - Print at 100% scale (no “fit to page”) to avoid resampling.
  - If bleed is required, pick files marked with bleed or add 3 mm (0.125") per edge.

## Print production
- DPI
  - 300 DPI for small formats and fine details
  - 150–200 DPI acceptable for large posters viewed at distance
- Color
  - Ask if the print shop converts to CMYK; supply CMYK variants when requested
  - Request a proof when color fidelity is critical
- Bleed and safety
  - Typical bleed: 3 mm (0.125") each edge
  - Keep live content within the safe margin to avoid trims
- Sizes
  - A‑series: A5, A4, A3, A2
  - US: 5x7", 8x10", Letter (8.5x11"), Tabloid (11x17")
- Stock
  - Matte for minimal glare; 200–300 gsm for premium feel
- Suggested workflow
  - Open vector/PDF in your editor
  - Verify size, bleed, and color profile
  - Export to press‑ready PDF/X if your shop requests it

### Optional CLI export (advanced)
- Inkscape (vector to print PDF at 300 DPI):
  - inkscape input.svg --export-type=pdf --export-dpi=300 --export-filename=output.pdf
- ImageMagick (PNG to CMYK TIFF soft‑proof, profile required):
  - magick input.png -colorspace sRGB -profile CMYK.icc output.tif

## Wallpaper tips
- Common sizes: 3840x2160 (4K), 2560x1440 (QHD), 1920x1080 (FHD), 1290x2796 (tall phones), 1179x2556 (iPhone), 1536x2048 (iPad)
- Choose equal or larger than your display; let the OS scale down
- Disable “stretch” and use “fit/center” to avoid distortion; crop only if needed

## Branding usage
- Do not alter core marks beyond allowed color/scale guidance
- Maintain clear space; avoid distortion, effects, or overlays that reduce legibility
- Use provided monochrome/inverse variants for dark/light backgrounds

## Versioning and naming
- Versioning: Semantic (MAJOR.MINOR.PATCH) per collection
- Filenames (example):
  - AA_<collection>_<variant>_<size>_<color>.<ext>
  - Example: AA_Poster_A3_Bleed_BlackGold.pdf
